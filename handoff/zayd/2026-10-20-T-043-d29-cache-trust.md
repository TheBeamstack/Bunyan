## Changed

- `packages/document/src/cachetrust.ts` (new): `hmacSha256Hex` (RFC 2104 on the in-house `sha256`),
  `signedCacheIndex`, `verifyCacheIndex`, `newInstallSecret` (32 CSPRNG bytes), `sameInstallSecret`.
  The MAC covers the canonical JSON of the envelope's four fields and every record, so reformatting keeps it.
- `cachekey.ts`: `sha256(...chunks)` returns bytes; `sha256Utf8Hex` is unchanged on top of it.
- `cacherestore.ts`: `GeometryCacheSource.installSecret` (required); `openCacheIndex` refuses an index whose
  `envelope.mac` this secret does not give; `GeometryCacheIndex.envelope` is `SignedCacheEnvelope`.
- `document.ts`: `DocumentOptions.geometryCacheSecret` (defaults to `geometryCache.installSecret`); a write
  envelope without a secret throws; `geometryCacheFiles` signs, and carries file records only when the read
  and write secrets are equal, since carried records are re-signed.
- Tests: `tests/geometry-cache-trust-d29.test.ts` (new, pure, 12); restore +2 and export +3 (real OCCT); the
  existing R3/R4 helpers now sign with the test install's secret.
