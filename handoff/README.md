# `handoff/`

One body per turn at `handoff/<seat>/<YYYY-MM-DD>-<turn-id>-<slug>.md`, linked from its
`docs/PHASE_LOG.md` abstract. The contract is `diwan/AGENTS.md`; `diwan/scripts/agent_finish.py`
refuses a turn whose body is missing or unlinked.

## Archived bodies

Every body written before 2026-09-06 is under `handoff/archive/<seat>/` (`diwan/docs/RULINGS.md`
R6, R34). It was **moved, not edited** — frozen evidence, addressable by path and by git history.
New bodies still go to `handoff/<seat>/`.
